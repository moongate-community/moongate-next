# Introduction

Moongate is a server runtime for Ultima Online shards. The current architecture
keeps runtime services explicit, stores editable shard data in YAML, and exposes
extension points for trusted plugins and Lua scripts.

The first documentation site focuses on the runtime surface that operators and
contributors need immediately:

- configuration and data layout
- command registration and execution
- Lua scripting modules
- plugin startup context
- generated API reference
